Detailed Description

Sole owner of the kernel log (klog) ring.

Replaces the former mutable global object g_klog. The character ring lives as a private member; the kernel console producer writes via putchar()/puts(), and consumers (SYS_KLOG readers, tests) drain via read()/clear().
