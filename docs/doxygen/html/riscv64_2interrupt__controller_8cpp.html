 Terminate a U-mode faulting task (issue #206 M2, mirrors aarch64_el0_fault_handler). Runs IRQ-masked from the trap entry; must not re-enable IRQs and must NOT call Scheduler::terminate (ISR-unsafe) — marks TERMINATED, wakes a waitpid parent, and arms the deferred switch via switch_away_from_terminating.
