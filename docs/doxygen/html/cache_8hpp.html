Detailed Description

Data-cache maintenance for DMA (issue #354 Slice C). Clean (write-back) before a device reads memory, invalidate after a device writes memory and before the CPU reads it (see dma.hpp contract). x86_64 is cache-coherent with DMA but the helpers are still correct there; QEMU virt is coherent on both non-x86 arches, so the riscv64 fence-only fallback is exact under emulation (#307 retains the non-coherent-silicon residual).
