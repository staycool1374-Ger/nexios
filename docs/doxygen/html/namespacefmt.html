int fmt::mini_vsnprintf ( char * out,
size_t cap,
const char * fmt,
VaList args )

Format into out (issue #286 contract, frozen by owner). Conversions: c s d i u x X p %%, flags -/0, decimal field width, .N precision for s only. Lengths: none = 32 bit, l/ll = 64 bit (LP64), z = 64 bit, hh/h ignored (default promotion applies). X renders lowercase hex (in-tree libc quirk, kept for a single shared contract). Unknown specifiers are copied literally (fail-closed); overlong width/precision is clamped.

Returns
Needed length excluding NUL (vsnprintf-compatible); output is truncated to cap - 1 chars + NUL when cap > 0, untouched when 0.
