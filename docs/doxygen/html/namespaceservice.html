enum class service::DebugdEnsure : uint64_t
strong

Ensure a live debugd for runelf --debug (issue #231 §9.5, #295 runtime now present). Returns the debugd pid, or 0 when unavailable. Reuses the live task behind the taskdefs pid cell (dead generations count as unset); otherwise spawns from the taskdefs row values (SPORADIC_SERVER, prio 2, SS(1,10,0) envelope per spec §10) via initrd find + validate + elf::load + add — mirroring the reboot_from_table SPORADIC_SERVER arm, but NOT the background ElfLoader (which would destroy the retained user completion). DaemonWatch array and the row's enabled=false flag are never touched. Spawn failure fails closed (0 → clean refusal). Failure stages are distinguished for diagnostics (missing ELF vs load/admission failure — both refuse identically safe).
