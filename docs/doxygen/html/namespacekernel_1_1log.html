◆ LogSeverity

enum class kernel::log::LogSeverity : uint8_t
strong

Severity of a dmesg entry (issue #234). Stored per entry so the renderer never re-derives it from the code (misclassification would mask faults as INFO — SIL 3 S1 guard: severity travels with the record).

Enumerator
DEBUG 

Verbose/trace, debug targets only.

INFO 

Action succeeded, confirmational.

WARN 

Unusual, system stable, maybe user action needed.

ERROR 

Operation failed, system handled it via an action.

FATAL 

Unrecoverable, safe state + halt, restart required.
