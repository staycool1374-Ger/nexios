◆ base_code_is_info()

bool kernel::log::base_code_is_info ( uint64_t code)
inline

True when a base-subsystem code is an informational event rather than a fault: daemon lifecycle (0xDA00-0xDAFF) and background ELF loader (0xDB00-0xDBFF) ranges. Used by the dmesg renderers to print INFO= instead of ERR=.

◆ base_error_string()

const char * kernel::log::base_error_string ( uint64_t code)
inline

Return a human-readable string for a base-subsystem error code. The code space is split into kernel::Error values (0–9) and a custom range for event codes: 0xDA00 – 0xDAFF daemon lifecycle events 0xDB00 – 0xDBFF background ELF loader events.
