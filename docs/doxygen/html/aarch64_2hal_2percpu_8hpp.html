Detailed Description

Per-CPU state block (issue #351, slice-2). One 4 KiB page per logical CPU, indexed by logical CPU ID. Accessed via TPIDR_EL1 (AArch64), mirroring the x86_64 GS_BASE approach in arch/x86_64/hal/percpu.hpp. Field offsets match the x86 layout so cross-arch readers (test isolation, debuggers) see one shape. CONFIG_MAX_CPUS pages; the BSP owns index 0, APs own 1...n.
