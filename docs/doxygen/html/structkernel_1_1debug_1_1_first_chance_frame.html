Detailed Description

Arch-neutral first-chance frame. Field slots are reused per arch: x86_64: addr=CR2, pc=RIP, sp=RSP, pgtbl0=CR3, pgtbl1=unused, vector/error as trapped. aarch64: addr=FAR, pc=ELR, sp=SP, pgtbl0=TTBR0, pgtbl1=TTBR1, vector=ESR. riscv64: addr=stval, pc=sepc, sp=SP, pgtbl0=SATP, pgtbl1=unused, vector=scause.
