Detailed Description

Arch-neutral per-task I/O-permission-bitmap (IOPB) interface (v0.4.2, issues #3/#8). x86_64: per-task TSS I/O bitmap delegation; other arches: no-op stubs. Issue #8 adds the grant ledger so revoking/disposing an IO MmioCap retroactively clears the granted port bits in live task bitmaps (closing the #3 revocation gap).
