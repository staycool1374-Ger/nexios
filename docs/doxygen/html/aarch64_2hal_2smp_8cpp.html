Detailed Description

AArch64 SMP AP bring-up (issue #351, slice-2). The BSP walks the DTB cpu nodes (slice-1 helpers), publishes the AP entry cells, then wakes each secondary with PSCI_CPU_ON (SMC/HVC conduit from the DTB psci node) as primary or the spin-table cpu-release-addr hold-loop as fallback. Woken APs run ap_main() (per-CPU + GIC + timer init) and idle on wfi with timer ticks live (Phase C scheduling lands in slice-4/5). Runs once at boot under interrupt guard; any failure parks with zero APs or panics naming the MPIDR — never half-woken. Single-CPU topologies (DTB cpu count <= 1) are a silent no-op.
