Detailed Description

Deterministic-boot stage tests (issue #45). Real assertions on the kernel::boot_stage_* API (main): validity + monotonicity + relative budget bounds. Sampling method: IrqGuard-frozen rdtsc measured-max + static loop-cap bounds, relative asserts with >=3x headroom; QEMU-TSC numbers are relative/scaling-only (wcet_analysis.md method). Raw-counter deltas are host-load-independent (instruction-driven under TCG), so all asserts rest on relative/raw properties — never absolute ns.
