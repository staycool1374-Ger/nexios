 True when rsp lies within t's kernel-stack range [base, top]. Returns false (without logging) when rsp is below the base; logs the overshoot when rsp is above the top. Diagnostic helper for validate_switch().
bool kernel::sched_verify::validate_switch (TaskControlBlock *current, TaskControlBlock *next, const char *label)
 Validate a context-switch pair before the deferred-switch publish (audit-scheduler-tasks LOW: the single home of the duplicated current/next validation). Accepts only non-null, higher-half pointers carrying the TCB magic; for a non-idle next also requires the pre-saved RSP to lie inside its kernel stack. Logs the first failure and returns false; the caller then reports the corruption.

bool kernel::sched_verify::validate_task_ptr (const TaskControlBlock *t, const char *label) noexcept
 Validate a task pointer at a Scheduler:: entry point (issue #369 T1a: the common non-null + higher-half + magic prefix of validate_switch, factored for registry/queue admission paths).
