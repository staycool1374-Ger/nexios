bool kernel::input::serial::loopback_begin ( )

Enter the MCR loopback window (riscv64 debug builds only). Fail-closed: false on other arches, in release, when already active, on a foreign LOOP bit, or on read-back mismatch. While active, pump() is inert and capture is suspended. No logging and no asserts may run inside the window (an abort would strand LOOP and silence the console suite-wide).
