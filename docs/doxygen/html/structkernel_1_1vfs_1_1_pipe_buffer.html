Detailed Description

Ring buffer shared between the read and write ends of a pipe.

Shared-ownership class (Class C): the two vnode endpoints each hold one reference; the creator holds a transient reference during create_pipe(). The last reference invokes dispose() (KernelObject), which returns the block to the MemPool. Refcount is atomic (SMP-safe) — the previous plain int refcount decrement raced on a multi-CPU target.
