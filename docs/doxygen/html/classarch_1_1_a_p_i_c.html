◆ set_timer_oneshot()

void arch::APIC::set_timer_oneshot ( uint64_t ns)
static

Program the APIC timer to fire once after ns nanoseconds. Uses TSC-deadline MSR when available; falls back to one-shot bus-clock mode. The interrupt is delivered at APIC_TIMER_VECTOR.

Parameters
nsDelay in nanoseconds (0 = no-op).
