Budget-replenishment discipline for SporadicServer (issue #22). Namespace scope so TaskDef/task APIs can name it without the class.

Enumerator
SPORADIC 

POSIX.1b per-activation replenishment (default).

DEFERRABLE 

Budget preserved across idle; periodic full top-up.

BACKGROUND 

Never above bg_priority_ (idle-time only).
