Detailed Description

RISC-V64 SMP AP bring-up (issue #351, slice-3). The BSP walks the DTB hart nodes (slice-1 helpers), probes SBI HSM, then wakes each secondary with HSM hart_start (the MMU-off ap_entry stub as start_addr, logical id as opaque). No spin-table or CLINT fallback exists: absent HSM support fails closed. IPIs use the legacy SBI hart-mask ecall (C2); the single S-mode software interrupt fans out via a per-hart mailbox (reschedule / shootdown / loopback). TLB shootdown applies per-batch-entry SFENCE.VMA with a bounded full-fence fallback. Woken APs run ap_main() and idle with timer ticks live (Phase C scheduling lands in slice-4/5). Runs once at boot under interrupt guard; any failure parks with zero APs or panics naming the hart ID — never half-woken. Single-hart topologies are a silent no-op. RISC-V-only.
