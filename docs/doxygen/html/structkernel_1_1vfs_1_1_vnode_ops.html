bool stable_ino = false
 Stable-ino filesystem marker (issue #333): true only for tables whose lookup assigns a computed key that is stable across independent resolves of the same object (fat32: parent-dir first cluster + dir-entry slot index; remove marks free without compacting). Lets the TOCTOU re-resolve accept same-object re-resolves that allocate fresh vnodes per lookup on a WRITABLE image. Gated additionally on ino/size/mode equality plus nonzero ino (root keeps ino 0 and always matches via the strict pointer path). Defaults false (strict pointer identity).

bool kernel::vfs::VnodeOps::readonly = false

Read-only filesystem marker (issue #332): true only for tables over an immutable image (initrd). Lets the TOCTOU re-resolve accept same-object re-resolves that allocate fresh vnodes per lookup. Defaults false (strict pointer identity); writable fses must NEVER set it, even on tables without namespace mutators (e.g. fat32_file_ops — mutability lives on the sibling dir table, so ops-shape alone cannot prove it).
