Detailed Description

Owns a contiguous PMM region and may be retyped at most once.

Shared-heap class (PipeBuffer/CNode pattern). The retype-once guard (retyped_) is the single ownership bit: while false the Untyped owns the region's frames and dispose() frees them; after a successful retype it owns nothing and the retyped capability (e.g. FrameCap) frees the frames. No path frees the same frames twice.
