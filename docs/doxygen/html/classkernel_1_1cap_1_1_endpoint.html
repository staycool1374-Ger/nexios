Detailed Description

A capability-gated IPC endpoint: a heap-resident message queue plus a receiver binding and badge. Shared-heap class (PipeBuffer pattern): lifetime is pinned by capability slots; dispose() runs on the last reference.

Note
The embedded MessageQueue is heap-resident and explicitly init()'d (never deleted — Endpoint is freed via MemPool::free in dispose(), so MessageQueue's destructor is not invoked; blocked senders must be drained before the last release).
