Detailed Description

Task create/cleanup step registries (issue #347 Slice C).

Two traced segments over TaskControlBlock::create()/cleanup(), one step per code block. Steps mirror the issue #324 12-step list; the code carries two extra blocks (exit-stats snapshot, cap/IRQ release), so the cleanup registry has 14 steps — the mapping is documented per enumerator. Conditional blocks (user stack, kslot, page tables) fold into their region's step: the step marks the region's completion, whatever sub-path it took.

Terminal paths (record a prefix, validate against nothing full): poisoned-TCB skip (empty chain), pinned early-return (Validate + WatchdogDisarm only), create()-OOM legs (partial chain — destroy() on the failure path runs cleanup(), which steps into the same slot).

Slot discipline (shared with the dispatch registry): tests own reset; production never resets or validates. Tests must hold IF=0 across reset → drive → capture: the timer ISR runs next_task(), whose dispatch steps would otherwise pollute the shared slot.
