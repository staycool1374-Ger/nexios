Detailed Description

Per-task execution-time metering tests (issue #21, v0.4.8).

DRIVEN: every property is reached through REAL dispatched tasks on real timer ticks — the harness never calls Scheduler::on_tick() to fake time and never mutates task accounting fields (v0.3.10 rework discipline). The SYS_TIMES copy-out path is driven through a REAL Ring-3 probe task (issue #143 fixture pattern), x86_64 only.
