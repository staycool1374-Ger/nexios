Detailed Description

Debugger syscalls (issue #225, spec docs/specs/debugd.md §3–§4). Five slots (86–90): attach (selector + id), read/write regs, read/write mem. Handles are kernel-minted (target, debugger, gen) bindings — never pids. Raw pid lookup does not exist; the only mint paths are launcher-claim (parenthood proof, selector 1) and supervisor grant (deferred to Phase 4 with debugd). Data calls on RUNNING/READY targets arm the deferred stop and return EAGAIN; BLOCKED tasks are read directly (frames stable). Release builds map these slots to sys_unimplemented (table level).
