Detailed Description

Debugger syscalls (issue #225, spec docs/specs/debugd.md §3–§4). Five slots (86–90): attach (selector + id), read/write regs, read/write mem. Handles are kernel-minted (target, debugger, gen) bindings — never pids. Raw pid lookup does not exist; the only mint paths are launcher-claim (parenthood proof, selector 1) and supervisor grant (selectors 7/8, issue #239; loop wiring in Phase 4 with debugd, issue #232). Data calls on RUNNING/READY targets arm the deferred stop and return EAGAIN; BLOCKED tasks are read directly (frames stable). Release builds map these slots to sys_unimplemented (table level). Control selectors need no new syscall numbers (ABI frozen): 2 = poll, 3/4 = breakpoint insert/clear, 5 = step, 6 = continue, 9 = stop-request (Ctrl-C hook, issue #232).
