Detailed Description

Static bounded IOMMU translation-table manager. All tables are fixed .bss allocations except per-domain SL pages (PMM, zeroed on allocation). One leaf SpinLock serializes all manager state; it is a leaf lock (never held while calling into cap/cspace layers, dispose() or MemPool::free; never held across reschedule()).
