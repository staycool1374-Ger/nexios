Detailed Description

Post-mortem user-task exit records (issue #294). A reaped task takes its TCB to the grave; this ring keeps the numbers that monstat user shows after the task is gone. Static POD, no allocation, ResourceTracker-neutral. Daemon exits never enter (same PID rule as the monstat finder).
