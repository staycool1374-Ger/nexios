Detailed Description

Physical memory manager using a bitmap to track free 4 KiB pages.

Note
All physical page allocation and deallocation goes through PMM. Tracks USER vs KERNEL page ownership for safety in free_user_pages.

Compute the allocatable window for a memory layout (pure).

The window is the first HHDM_WINDOW_SIZE bytes of RAM starting at window_base, clamped to the bitmap span (mem_size). base_page == end_page encodes an empty window (window_base beyond the span).
