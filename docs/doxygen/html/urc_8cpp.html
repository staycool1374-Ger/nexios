Detailed Description

Bounded prefix-registered async console queue (issue #407 item 2). FIFO of frozen "[PREFIX] payload" lines; producers emit (ISR-safe), only the shell task pops at prompt redraw. Drop-newest on full with a counted notice; unknown tag / null line / sealed table are counted rejects, never ENSURE. Static storage only. Lock order: urc lock is a leaf (scheduler_lock_ -> urc lock is the only allowed nesting; no call out of the guarded region).
