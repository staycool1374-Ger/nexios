Detailed Description

VFS daemon authorisation tests.

v0.3.10 rework (SIMULATED → DRIVEN): every VFS syscall runs inside a REAL kernel task (prio ≥ 11) that is genuinely dispatched — the handler's syscall_task() resolves to the running task and the kernel-bypass / daemon authorisation path is exercised through real execution. The harness never calls Syscall::handle() directly.
