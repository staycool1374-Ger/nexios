bool kernel::block::VirtioBlkDriver::handle_irq ( )

ISR entry — drains the used ring, records the completion and wakes the armed waiter. Interrupt context: no blocking, no allocation, completion lock only, wake applied outside the lock.

Returns
true when a completion was consumed.

◆ test_simulate_irq_armed()

void kernel::block::VirtioBlkDriver::test_simulate_irq_armed ( )
inline

Test-only: simulate an armed IRQ vector without PCI MSI/MSI-X (the mock transport has no MSI capability, so enable_irq() fail-closes). Delivery is simulated by calling handle_irq() directly. Never touches PCI/IDT state (allocated_ stays false). Not for production.
