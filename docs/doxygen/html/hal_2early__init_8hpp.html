Detailed Description

Early IRQ-controller + architectural timer init contract (issue #198). Single per-arch entry point run before the scheduler exists: IDT init/load, controller init, timer init, timer calibrate — with global IRQs masked throughout. Fail-closed via EarlyIrqResult; reachable failures never panic.
