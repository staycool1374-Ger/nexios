void verify_booted_aps ()
 One-shot cross-CPU SGI verification (issue #351, slice-2). Called once from the BSP idle-loop entry (post-gate, IRQs live, APs IRQ-live): sends each parked AP the loopback SGI and polls its ack. ◆ scheduler_started()

bool kernel::smp::scheduler_started ( )

True once the scheduler start-gate is published (issue #389). Fan-out targets park pre-gate (no drain yet), so the shootdown hook fans out only when true — matching the x86/rv64 contract.

True once the scheduler start-gate is published (issue #389). Fan-out targets park with IF=0 until this lands (Phase-B behavior), so the shootdown hook fans out only when true — otherwise the target cannot drain and every flush burns its bounded spin.

Returns
True after publish_scheduler_ready(), false before.
