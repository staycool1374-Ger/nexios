static constexpr SyscallNumber k_syscall_fast []
 Audited pointer-free syscall subset (issue #92). A member must NEVER dereference a user pointer — the FAST path skips the canary + (debug) SMAP/AC checks. SEND/RECEIVE/SEND_SYNC are intentionally excluded (they touch user buffers via checked_ptr / safe_copy_to_user).
