Detailed Description

Virtio-blk request-path tests (milestone v0.4.3 issue #117). Drives VirtioBlkDriver against a mock VirtioTransport (plain in-memory common/notify/device config — the sanctioned mock-hardware pattern) and completes requests from a REAL higher-priority task acting as the device (reads the avail ring through HHDM, services the descriptor chain, advances the used ring), exercising descriptor chaining, notify, response parsing and completion cookies end-to-end.
