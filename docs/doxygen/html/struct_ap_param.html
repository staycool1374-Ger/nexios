Detailed Description

Per-AP HSM handoff block (see ap_entry.S). Lives in a PMM page (PA native, no translation needed); the BSP passes its PA as the HSM opaque argument. All HH addresses are link-time constants, valid once the AP installs the provided root (which covers the whole kernel). Layout matches the stub's fixed offsets — keep in sync with ap_entry.S.
