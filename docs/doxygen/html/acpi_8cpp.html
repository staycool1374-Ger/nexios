Detailed Description

ACPI DMAR discovery implementation (issue #9). The boot page tables identity-map only the first 128 MiB, but QEMU places ACPI tables near the top of RAM, so every accessed page is explicitly mapped on demand (HHDM + VMM::map_page, APIC/framebuffer pattern). Every table access is bounds-checked against the declared length and every signature.

  • checksum is validated before the data is trusted (fail-closed probe).
