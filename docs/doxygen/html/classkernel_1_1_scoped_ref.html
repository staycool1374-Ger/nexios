Detailed Description

RAII scoped reference guard for KernelObject objects.

Acquires on construction and releases on destruction. Used to pin a shared/pool-backed object while a code path that is not serialized against the owner's teardown dereferences it. Safe on shared objects — that is its purpose. If acquire() refuses (revoked object), the pin is a no-op.

Note
Contract: a ScopedRef must never outlive the owning task's teardown for a private-owned (non-shared) object. release_all_objects() asserts refcount==1 for non-shared nodes; a pin still live at teardown trips that assert (debug) or drops the ownership ref early. For shared objects the assert is skipped (>=1 only) and a pin merely delays the last release until it goes out of scope.
