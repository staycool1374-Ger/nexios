Detailed Description

Boot-time framebuffer backing store for non-x86 virtio-gpu/ramfb backends (issue #394). Guest-RAM scanout: the device reads pixels from this buffer, so no VMM Device/UC remap is needed.

Note
PMM-backed, NOT static BSS: a 4 MiB static backing trips the riscv64 boot.S fail-stop (kernel_phys_end must stay below 0x80C00000 for the fixed .boot_stack_rv + PMM metadata slack). PMM pages allocated during boot precede the test-isolation baseline, so the ResourceTracker delta stays zero — same discipline as virtio-blk queue pages.
