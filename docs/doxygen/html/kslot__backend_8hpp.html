Detailed Description

#434 P1: arch-neutral kslot window backend interface (SPEC §3.1).

Shared mechanism (slot pool, first-fit+bump, guard+stack layout, snapshot framing, teardown order) lives once in task.cpp and calls ONLY these hooks. Per-arch mechanics (window table wiring, leaf flags, TLB maintenance) live in build-selected TUs: src/kernel/arch/x86_64/kslot_backend.cpp src/kernel/arch/aarch64/kslot_backend.cpp src/kernel/arch/riscv64/kslot_backend.cpp C3 binding: zero CONFIG_ARCH/#if ARCH in task.cpp alloc/free/map/call paths outside this backend. Per-arch nexios_config.h window defaults are permitted config (not a memory-path carve-out).
