Detailed Description

IOMMU DMA protection manager (v0.4.2, issues #4 + #9): capability- gated, identity-IOVA second-level translation tables in memory (VT-d layout, vtd.hpp) plus live VT-d enablement (issue #9). Iteration-1 (#4) programs TABLES ONLY. Phase-2 (#9) adds: ACPI DMAR discovery, a real hardware probe, register-level enablement (RTADDR + kernel passthrough pre-pass + GCMD.TE) and IOTLB/context-cache invalidation after every SL/context mutation when a live unit is present. The live path is strictly gated on g_live — with no IOMMU present all calls fail gracefully and kernel DMA is untouched.
