Detailed Description

SMP AP bring-up (issue #25, Phase B). The BSP copies the position-locked trampoline blob to physical 0x70000, fills the param block, and wakes each MADT-listed AP with INIT + SIPI; woken APs run ap_main() (per-CPU init + LAPIC enable) and park in a halt loop (scheduling on APs is Phase C). Single-CPU runs (MADT ncpus <= 1 or block unusable) are a silent no-op. x86_64-only.
