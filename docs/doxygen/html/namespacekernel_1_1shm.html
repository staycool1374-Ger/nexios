struct  SharedRingHeader
 Shared ring header — lives at the start of page 0 of the frame cap. The head (producer-write-only) and tail (consumer-write-only) are cache-line aligned (64 bytes) to avoid false sharing on future SMP. layout is fixed and documented (docs/specs/shm.md). More...

 Initialises a shared ring header at header (must be the start of page 0 of a frame cap with frame_count pages). element_size must be a positive multiple of 8. The ring data capacity is (frame_count - 1) * PAGE_SIZE; it is rounded DOWN to a power of two so the head/tail wrap mask works. Called by the producer once, before either side maps/uses the ring.

Initialises a shared ring header at header (must be the start of page 0 of a frame cap with frame_count pages). element_size must be a positive multiple of 8. The ring data capacity is (frame_count - 1) * PAGE_SIZE; it is rounded DOWN to a power of two so the head/tail wrap mask works. Called by the producer once, before either side maps/uses the ring.

Parameters
headerPointer to the header area (page-0 start).
frame_countNumber of pages in the backing FrameCap (>= 2).
element_sizeFixed element size in bytes.
