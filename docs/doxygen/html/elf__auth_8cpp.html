Detailed Description

Read-only segment CRC baseline + re-verify primitives (issue #46).

Coverage rule: every PT_LOAD segment WITHOUT PF_W, byte range [vaddr, vaddr+filesz). Writable segments mutate by design (GOT, data, stack), the BSS tail carries no file signal, headers are never mapped. Both the loader baseline scan and the idle re-verify slice use these helpers, so the compared values are self-consistent by construction.
