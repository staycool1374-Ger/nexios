Detailed Description

procfs operation-contract tests (milestone v0.4.10 issue #124). test_vfs_procfs.cpp covers the content paths (read/fstat/ readdir/lookup); the remaining 36 functions — every open/close, every not-supported write/ioctl/readdir/lookup and the per-node lseek implementations — were never entered. This class drives each of them on the real proc_fs vnodes.
