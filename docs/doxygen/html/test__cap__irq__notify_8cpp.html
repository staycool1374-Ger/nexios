Detailed Description

User-space IRQ delivery — NOTIFY mode tests (issue #7): the hardware IRQ dispatcher transforms incoming interrupts into capability-backed IPC notifications on the recipient task's Notify (eliminating Ring 0 driver execution). Real ISR vectors are NOT injected — the harness drives IrqDelivery::isr_entry directly (deterministic, no hardware dependency). Vector 40 (RTC, IRQ8) is used throughout: its periodic interrupt is disabled at boot, so no spurious delivery perturbs the tests.
