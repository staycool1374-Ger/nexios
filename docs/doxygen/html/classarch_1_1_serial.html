void arch::Serial::init ( )
static

Initialise the serial port hardware.

Initialise the serial port (COM1) at 115200 baud, 8N1.

Initialize the serial port (no-op on RISC-V64). The virt 16550A divisor is pre-initialized by OpenSBI/QEMU; reprogramming it risks breaking the S-mode SBI TX path, so RX-only polling attaches to the live configuration (issue #247).

Initialise the PL011 UART at 115200 baud (default QEMU virt config). Disables UART, clears pending interrupts, sets baud rate, enables TX/RX.

bool arch::Serial::poll_getchar ( char & c)

Non-blocking receive poll (issue #245: the interactive shell has no input source on architectures without PS/2 — the x86 COM1 inline poll and the Keyboard stub both miss the UART). True with the oldest pending byte iff RX data is ready; false immediately otherwise (never waits, never spins). riscv64 polls the virt 16550A LSR (issue #247).

Non-blocking receive poll (issue #245).

Non-blocking receive poll (issue #247): the interactive shell's only input source on riscv64 (no PS/2, Keyboard is a stub). Zero-wait LSR check — never spins, so the shell nap loop keeps its 20ms latency bound even when the FIFO is empty.

Non-blocking receive poll (issue #245): the interactive shell's only input source on aarch64 (no PS/2, Keyboard is a stub). Zero-wait FR check — never spins, so the shell nap loop keeps its 20ms latency bound even when the FIFO is empty.
