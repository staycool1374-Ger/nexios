Detailed Description

Architecture-neutral context-ID (PCID/ASID) API (issue #352).

Thin wrappers over the per-arch allocators so generic kernel code (task create/cleanup, scheduler root publication) never branches on the architecture:

  • x86_64 delegates to pcid_* (arch/x86_64/hal/pcid.hpp).
  • aarch64 delegates to asid_* (arch/aarch64/hal/asid.hpp, 8-bit).
  • riscv64 delegates to asid_* (arch/riscv64/hal/asid.hpp, 16-bit).

ID 0 (CONTEXT_ID_KERNEL) is reserved for the kernel root on every arch and means "untagged" to context_id_tag. A live ID is never reissued by any backend (bitmap-checked).
