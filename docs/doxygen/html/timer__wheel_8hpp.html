Detailed Description

Per-CPU O(1) event-timer wheel (issue #17, v0.4.7).

Static slot-table queue powering bounded sleeps, driver timeouts, deadline release queues, and watchdog pre-timeouts. Pure callee of the system tick: never programs timers, never reads the tick source (the caller passes now_ns), never blocks or reschedules. Callbacks run in tick context and must only set flags / mark wake objects — deferred wake application belongs to task context (#18 producers).
