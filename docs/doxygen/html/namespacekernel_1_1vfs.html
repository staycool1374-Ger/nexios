bool vnode_identity_match (const Vnode *before, const Vnode *after, uint64_t ino_before) noexcept
 Re-resolve identity for TOCTOU closure (issues #332/#333, spec §4). Strict fast path (same object + same ino, e.g. tmpfs stable entries) OR immutable-equivalence: same ops table, same ino/size/mode, gated on the filesystem-declared VnodeOps::readonly marker (initrd tables only — per-lookup vnodes over a read-only image, where replacement across the authorize yield is impossible) OR stable-ino equivalence: same ops table, same nonzero ino/size/mode, gated on the filesystem-declared VnodeOps::stable_ino marker (fat32 tables only — lookup assigns a computed slot key that survives independent re-resolves; slot reuse after unlink is narrowed by the size+mode co-check). Both gates are deliberately NOT ops-shape: mutability may live on a sibling table (fat32 file tables carry no mutators yet the image is writable), so only an explicit declaration admits equivalence. Fail-closed (any null/mismatch denies). Pure comparisons, no locks, no syscalls.

◆ create_pipe()

int kernel::vfs::create_pipe ( int fds[2])

Create a pair of connected pipe file descriptors.

Returns
0 on success, VFS_INVALID on failure.

Refcount handoff (creator-ref -> two-end-refs):

  1. alloc + placement-new: refcount=1 (creator), mark_pool_backed.
  2. alloc rnode/wnode — failure -> pb->release() (1->0 -> dispose).
  3. alloc rfd/wfd — failure -> pb->release() (creator) + free vnodes/fds.
  4. set vnode fields incl. private_data = pb (NOT published yet).
  5. pb->acquire() for read end, pb->acquire() for write end -> refcount 3.
  6. publish both vnodes into the fd_table slots.
  7. pb->release() (creator drop) -> refcount 2 (one per endpoint). Every error path is a single symmetric release of the references taken so far; no path can double-free or leak the block.
Parameters
[out]fdsArray of two descriptors: fds[0] for read, fds[1] for write.
Returns
0 on success, or VFS_INVALID on failure.

◆ readdir_merged()

int kernel::vfs::readdir_merged ( Vnode & dir_vnode,
uint64_t & pos,
Dirent & dent )

Read a directory entry, overlaying child mount points (#346).

Read a directory entry, overlaying child mount points (#346). Phase 1 delegates to the vnode's own readdir while it returns 0; on underlying EOF the mount table is scanned for mounts whose parent resolves to this vnode (spelling-independent via resolve() + vnode_identity_match), skipping names already yielded by phase 1. Holds no locks itself; stateless across calls except the caller-owned position. Null readdir ops are treated as an empty underlying phase.

Returns
0 with dent filled, or VFS_INVALID when exhausted.
