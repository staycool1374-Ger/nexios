Detailed Description

Single definition point for all cross-TU kernel globals.

Every symbol defined here has exactly one owner file (this one). Symbols are defined at the SAME scope as their historical extern declarations so existing consumers keep linking; the gs:: accessors are the sanctioned way to read/write them.
