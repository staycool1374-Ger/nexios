Detailed Description

x86-64 CPU context — general-purpose registers, interrupt vector, error code, and interrupt-frame (rip, cs, rflags, rsp, ss).

RISC-V 64 CPU context — general-purpose registers, S-mode CSRs, interrupt vector, and error code.

AArch64 CPU context — general-purpose registers x0–x30, SP_EL0, ELR_EL1, SPSR_EL1, interrupt vector, and error code.
