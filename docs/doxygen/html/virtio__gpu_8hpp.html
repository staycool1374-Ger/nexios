Detailed Description

virtio-gpu control-queue driver over legacy-v1 virtio-MMIO (issue #394 Slice A). Guest-RAM 2D scanout: no BAR, no VMM remap — the device reads pixels from the static fb_backing buffer (phys via VMM::virt_to_phys_err). Device IDs: 0x1050 modern / 0x1010 legacy (MMIO DeviceID 16). Command wire formats follow Virtio 1.2 §5.7.
