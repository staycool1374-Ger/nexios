Detailed Description

User-space MMIO page-frame mapping tests (issue #8): the SYS_MMIO_MAP/SYS_MMIO_UNMAP syscall surface, the MmioUserMap registry (fixed user VA window), user-PML4 mapping resolution, revoke-invalidate, cleanup drain and registry exhaustion. Real device BARs are NOT accessed — the tests wrap a PMM page in an MmioCap and drive the registry/syscalls deterministically.
