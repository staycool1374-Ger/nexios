◆ init() [2/2]

void arch::RTC::init ( )
static

Initialise the RTC (enable periodic interrupt if needed).

Initialise the RTC. Configures 24-hour mode and binary (non-BCD) format, disables periodic and update-ended interrupts, and clears Status Register C.

Discover the Goldfish RTC from the DTB, validate, and probe. Idempotent; never panics; fail-loud (one WARN) to mtime fallback.

Probe the PL031 signature, start the counter, latch the base. Idempotent: the first successful (or failed) probe wins; the base is published once. Never fails closed into a panic — worst case the counter reads while stopped (still monotonic from the reset value).
