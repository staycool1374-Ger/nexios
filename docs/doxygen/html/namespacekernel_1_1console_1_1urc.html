◆ emit()

bool kernel::console::urc::emit ( Tag tag,
const char * line )
nodiscard

Enqueue one async line (ISR-safe, bounded, never blocks). The line is frozen at enqueue ("[PREFIX] " + payload, truncated with "..." past kLineMax-1). Full queue drops the new line and counts it (drop-newest: the queued prefix of history survives). Unknown tag or unregistered prefix is a counted reject, never ENSURE.

Parameters
tagProducer tag (< Tag::Count, prefix registered).
lineNUL-terminated payload (nullptr => counted reject).
Returns
true iff the line was queued.
