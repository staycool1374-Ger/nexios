Detailed Description

User-space frame mapping registry (issue #106 Part B). A static bounded table keyed by task id (MmioUserMap pattern) that maps a FrameCap's frames into a fixed user VA window for Ring 3 shared memory via the SYS_FRAME_MAP/SYS_FRAME_UNMAP syscall surface. Keyed by owner_task_id + a per-slot generation (recycled-slot stale-VA defense). No dynamic allocation on RT paths. Lock order: scheduler_lock_ -> frame map lock (never held across VMM map/unmap or reschedule).
