Pop the highest-priority message only if it fits max_size. Fail-closed for the IPC fastpath (issue #11, paper §3.9): an oversized best match is NOT removed (returns false). Callers disambiguate empty-vs-oversized with is_empty().

Remove the highest-priority message only if it fits max_size.

Returns
true if a fitting message was dequeued; false if the queue is empty OR the best match is oversized (NOT removed — fail-closed, issue #11 paper §3.9). Callers disambiguate with is_empty().

bool kernel::MessageQueue::pop_from_sender ( Message & out,

Pop the highest-priority message from sender_id only (issue #296): non-matching messages are never touched, so a send_sync waiter cannot eat another sender's message as its reply. FIFO within a priority among matching (INV-P kept).

Remove the highest-priority message from sender_id (issue #296). Non-matching messages are never touched.

Returns
