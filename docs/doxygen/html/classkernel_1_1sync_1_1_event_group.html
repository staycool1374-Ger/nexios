◆ wait_bits()

uint64_t kernel::sync::EventGroup::wait_bits ( uint64_t wanted,
bool clear_on_exit = false )

Block until any of the requested bits are set.

Parameters
wantedBitmask of bits to wait for.
clear_on_exitIf true, clear matched bits before returning.
Returns
The bits that were set when the wait completed.

Never holds the spinlock across Scheduler::reschedule() (same deadlock exposure as the semaphore). Waiter-table-full is reachable exhaustion: a retry condition, never ENSURE.
