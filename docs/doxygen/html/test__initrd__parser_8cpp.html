Detailed Description

initrd cpio-newc parser tests (milestone v0.4.3 issue #112): synthetic in-memory archives driving find()/readdir() through corrupt magic, truncation, TRAILER handling, path normalization and enumeration ordering.

Note
Every test installs its synthetic archive via initrd::init(), captures results into locals, RESTORES the boot initrd (linker-provided _binary_initrd_cpio_start/end) and only then asserts — assertion early-return can never leave a poisoned initrd for later tests.
