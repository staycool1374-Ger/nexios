Detailed Description

Compile-time build identity (issue #357): architecture, build type, debug flag, pointer width, and framebuffer backend. Values arrive as bare preprocessor tokens from the Makefile (-DNEXIOS_ARCH_NAME=$(ARCH), -DBUILD_TYPE=debug|release — never quoted, per the #244 rule) and are stringified here. Constexpr-only: no runtime state, no thread interaction.
