Detailed Description

Serial-injected key decoder (issues #355, #407). Ring core is compiled on all arches (x86_64 included since #407: the shell consumes UART RX through the ring everywhere); only the arch::Keyboard facade stays non-x86 (x86_64 owns the i8042 Keyboard implementation).
