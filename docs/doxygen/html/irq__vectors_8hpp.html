Detailed Description

Per-arch user-IRQ capability windows (issue #354 Slice B). IrqCap wraps platform IRQ lines (not MSI-X vectors — those belong to MsixCap on x86_64 only): x86_64 PIC IRQ1–15 (vectors 33–47; 32 is the scheduler tick), aarch64 GIC SPI window (INTIDs 32–255; SGI/PPI incl. the timer PPI 30 are never user-claimable), riscv64 PLIC sources (1–95; 0 is the never-signalled source).
