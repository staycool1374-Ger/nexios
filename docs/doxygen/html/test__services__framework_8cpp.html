Detailed Description

Services framework tests (milestone v0.4.10 issue #125): the non-command parts of services — the Terminal rendering surface (colors, cursor, splash, framebuffer gate, scroll) and the ProgramRegistry lookup API — were never entered.

Note
Terminal::readline() is deliberately not driven: it blocks on serial/keyboard input. Every test restores the terminal state it mutates (colors, framebuffer gate) so later output is unaffected.
