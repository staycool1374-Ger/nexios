Detailed Description

Checked RAII guard for scheduler_lock_ ONLY (#417). Drop-in replacement for SpinLockGuard<sync::SpinLock> on scheduler_lock_: the blocking constructor takes the lock, the adopt constructor takes ownership of a lock acquired via try_lock(); both mark this CPU's depth slot, the destructor (or early unlock()) clears it. Mark AFTER a successful take and unmark BEFORE release, so an observer never sees a taken-but-unmarked slot (a same-CPU re-take then trips the entry ENSUREs deterministically); another CPU's slot is never touched, so legal cross-CPU contention spins instead of tripping (the #417 fix). Free functions must not outlive the scope (same rule as SpinLockGuard).
