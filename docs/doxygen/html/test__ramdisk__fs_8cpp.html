Detailed Description

Ramdisk flat filesystem (issue #314) tests: mount presence, create/write/read/delete round-trips, bounds rejection, partial overwrite behavior, and loadelf-from-ramdisk acceptance. All ramdisk_fs vnode lookups return fresh owned nodes (refcount 1) — every test releases each resolved vnode exactly once (leaks fail the snapshot check). Unique filenames per test + setup-unlink isolate tests sharing the single /mnt/ramdisk mount (backing blocks persist across snapshot_restore by design, like daemon CSpaces).
