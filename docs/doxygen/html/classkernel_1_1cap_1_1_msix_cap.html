Detailed Description

A capability-gated MSI-X vector on a PCI device. Does NOT own the MSI-X table memory (device memory is never PMM-owned) — dispose only re-masks the entry, releases the delivery-table slot, frees the vector and the MemPool block. Shared-heap class (IrqCap pattern).
