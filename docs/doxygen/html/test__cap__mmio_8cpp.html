Detailed Description

MMIO caps + fine-grained I/O delegation tests (issue #3): MmioCap lifecycle, capability-gated MMIO mapping, TSS I/O bitmap layout, sys_ioport_grant dispatch + validation, per-task bitmap switch/cleanup. Ring-3 #GP on denied ports is NOT testable from the ring-0 harness — the tests assert bitmap state, TSS descriptor layout and owner bookkeeping instead.
