 Initialises a shared ring header at header (must be the start of page 0 of a frame cap with frame_count pages). element_size must be a positive multiple of 8. The ring data capacity is (frame_count - 1) * PAGE_SIZE; it is rounded DOWN to a power of two so the head/tail wrap mask works. Called by the producer once, before either side maps/uses the ring.

Detailed Description

Shared-memory ring protocol (issue #106 Part B). A SPSC ring living in the physical frames of a FrameCap shared by two user tasks via SYS_FRAME_MAP. Page 0 holds the SharedRingHeader (magic/version/capacity + cache-line-aligned head/tail); data pages 1..N-1 hold the ring payload. Zero-syscall after mapping: producer/consumer access the shared frames directly. Head/tail follow the SPSCRing acquire/release protocol (single producer / single consumer — never written by the other side).
