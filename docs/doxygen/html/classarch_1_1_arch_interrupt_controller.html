void arch::ArchInterruptController::init ( )
inlinestatic

Initialise both PICs in cascade mode with vector offsets.

Initialise the GIC distributor, CPU interface, and redistributor. Full GICv2 bring-up: version from GICD_PIDR2 (TYPER holds no version), distributor reset, priority/target/edge programming, timer PPI enable. BOOT_ONLY: repeat calls return without touching live state.
