Detailed Description

RISC-V64 SMP AP bring-up (issue #351, slice-3). The BSP discovers harts from the DTB (slice-1 helpers), then wakes each secondary with SBI HSM hart_start (start_addr = the MMU-off AP entry stub; no spin-table or CLINT fallback exists — absent HSM support fails closed). IPIs use the legacy SBI hart-mask call (C2: no CLINT mapping, probe-then-fail-closed); the single S-mode software interrupt fans out via a per-hart mailbox (reschedule / shootdown / loopback). TLB shootdown applies per-batch-entry SFENCE.VMA with a bounded full-fence fallback. Woken APs run ap_main() (per-hart + PLIC + timer init) and idle with timer ticks live (Phase C scheduling lands in slice-4/5). Single-CPU runs are a silent no-op. RISC-V-only.
