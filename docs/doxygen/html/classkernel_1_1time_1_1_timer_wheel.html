Arm a one-shot expiry (O(1)). Fail-closed: false on invalid cpu, null callback/context-out, or a full wheel (caller keeps its fallback; no eviction).

uint32_t cpu )
staticnoexcept

Tick hook: fire due expiries for one CPU (bounded). ISR-safe: try-lock, skip on contention (fires next tick instead). Fires at most kMaxExpirePerTick earliest-due callbacks; the lock is released before callbacks run (re-entrant arm/cancel safe).

Parameters
now_nsCurrent monotonic ns (caller-provided, #16 clock).
