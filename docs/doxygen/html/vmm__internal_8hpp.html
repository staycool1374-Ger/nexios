Detailed Description

VMM translation-unit-shared internals (issue #363): test-time kernel-VA touch notifiers, throttled-diagnostic helpers, the Sv39 HHDM slot constant, and page-offset/base masks. Single definitions live in vmm.cpp; the other vmm_*.cpp TUs link against these declarations.

Mask-home classification (issue #363 P3, owner decision 2): HAL-specific encodings live in hal/ (x86 NX bit: arch::ArchPageTable::NX). Kept here are TU-local shapes: the offset masks (used by shared skeletons on all arches), kHhdmL0Idx and the Sv39 index geometry (VMM-owned; the riscv HAL keeps its own private copies — that duplication is a known residual, not a contract). PAGE_FRAME_MASK and friends stay in vmm.hpp: they are VMM vocabulary shared by skeletons and helpers alike.

Walk-ownership residual (issue #363 P4, converged issue #378): arch leaf-codecs moved to the per-arch TUs (vmm_arch_* helpers, guards-in-file), plus walk-geometry shims (vmm_arch_walk_levels + vmm_arch_walk_indices) so all five walk sites share index computation with no per-arch #if. Shared walk skeletons stay VMM-private by design (snapshot pairing, ENSURE ownership checks, drop-note throttling are VMM policy, and the HAL walks current-root tables only); the two map bodies keep explicit per-arch descends (split placement, #361 injector and flag conditions differ), and unmap reuses pte_leaf_in_pml4. HAL attr_from_flags was deliberately NOT reused: it adds SH/NS + AP policy bits the VMM map path omits, so rewiring would change PTE bits (audited rationale).
