◆ StatePhase

enum class kernel::gs::StatePhase : uint8_t
strong

Kernel lifecycle phase. Drives the BOOT_ONLY write class: a global may only be written while the system is in the matching phase.

Enumerator
PRE_BOOT 

Before higherhalf_entry (assembly / early boot).

BOOT 

higherhalf_entry running (single CPU, IRQs off).

RUNNING 

Post-init, normal operation (daemons + user tasks).

TEST 

Test harness active (debug builds, selftest classes).

◆ WriteClass

enum class kernel::gs::WriteClass : uint8_t
strong

Write-permission class attached to each registered global.

Enumerator
BOOT_ONLY 

Only valid during StatePhase::BOOT.

IDEMPOTENT 

Setting the same value again is a no-op (e.g. bool→true).

OWNER_ONLY 

Writer task id must match a fixed owner.

RANGE_CHECKED 

Pointer/value must lie in a legal kernel range.

NEVER_WRITE 

Read-only after construction (Filesystem table).

PLAIN 

No extra rule (documented hot/fault-atomic paths).
