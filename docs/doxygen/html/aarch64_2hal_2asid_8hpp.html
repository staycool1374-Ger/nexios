Detailed Description

Address-space identifier allocator (issue #352, aarch64 only).

ASIDs tag TLB entries so TTBR0 switches between user address spaces retain translations instead of flushing. ASID 0 is reserved for the kernel (TTBR1); user address spaces allocate 1..255 (safe 8-bit range — wider hardware ASIDs are deliberately unused). On exhaustion the allocator bumps an epoch, issues one global flush, and restarts from 1 — a live ID is never reissued (bitmap-checked).

Mutation happens at task create/cleanup only (never on the timer-ISR or context-switch hot path). Purge-before-free: the freed ID's entries are flushed before the ID returns to the pool.
