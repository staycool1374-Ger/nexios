Detailed Description

Allow-list wrappers over the generated P2 stubs. Each wrapper forwards its arguments verbatim and returns the stub result unchanged: handles, mapping addresses, IRQ vectors and OK(0) pass through; failures arrive as -1 with errno set (the stub map_err already applies the section 2 predicate). No branches, no ENSURE, no handle inspection: every policy decision (rights, dst binding, table-full) fails closed kernel-side at lookup/install time, so there is nothing to re-check here.
