void arch::Keyboard::handle_irq ( )
static

Handle a keyboard interrupt — read scancode and enqueue character.

IRQ handler for keyboard interrupts. Reads the scancode from the PS/2 data port, updates modifier key states, translates the scancode to an ASCII character, and pushes it onto the ring buffer.

bool arch::Keyboard::try_forward_to_iocd ( uint8_t scancode)
static

Forward a raw scancode to the iocd daemon (issue #340 P1). Task context only: returns false in ISR context (never IPC-sends from an interrupt), when no daemon runs, or when the send is refused — the caller falls back to the legacy ring path.

Forward a raw scancode to the iocd daemon (issue #340 P1). Task context only: ISR context (isr nesting nonzero), no daemon, or a refused NONBLOCK send all fail closed so the caller keeps the legacy ring push and no keystroke is lost.

Parameters
scancodeRaw PS/2 set-1 byte (press or release).
Returns
true when the daemon accepted it (caller must skip the ring push — never both), false otherwise.
