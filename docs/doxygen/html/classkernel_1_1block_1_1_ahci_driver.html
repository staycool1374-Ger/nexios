◆ match_completions()

void kernel::block::AhciDriver::match_completions ( uint32_t busy,
uint32_t armed_mask,
uint32_t is,
uint32_t * out_done,
uint32_t * out_error )
static

Pure completion matcher (#64, unit-testable without hardware): which armed slots complete given CI/SACT/IS snapshots. A slot completes when its CI bit cleared (non-NCQ) or both CI and SACT cleared (NCQ, SDBS path). TFES snapshots mark the error bit.

Parameters
busyCI|SACT snapshot (bit set = slot still issued).
armed_maskBit set = slot has an armed waiter.
isPORT_IS snapshot (TFES = error).
out_doneMask of armed slots that completed (non-null).
out_errorMask of completed slots with TFES set (non-null).
