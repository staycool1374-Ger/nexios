bool arch::pan_init ()
 Detect + enable aarch64 PAN (FEAT_PAN), MP-4.4. Sets SCTLR_EL1.PAN (bit 23) when ID_AA64MMFR1_EL1.PAN[23:20] != 0 and CONFIG_PAN is on, then defaults PSTATE.PAN to deny (clac). Every PAN sysreg/SCTLR access is gated on this detection — an access on a CPU without FEAT_PAN raises an UNDEFINED exception at EL1.
