◆ kTaskEndDmesgClean

uint64_t kTaskEndDmesgClean = kernel::log::kDmesgBase_USER + 1
constexpr

Delivers a signal to a user task by setting up a signal frame on the user stack. Modifies regs to return to the user's registered signal handler (or terminates the task if no handler is registered and the default action is to terminate).

Returns
true if signal was delivered (handler will run), false if task was terminated.

dmesg records for task-end reports (issue #234): clean exit vs fault/signal death, canonical USER subsystem (kDmesgBase_USER). Legacy 0xDC01/0xDC02 codes keep decoding via base_error_string.
