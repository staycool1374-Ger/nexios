Detailed Description

Kernel-half page-table merge tests (issue #96).

Verifies VMM::merge_kernel_half (link semantics: missing entries are copied by value, present entries untouched, zero allocations) and the template/convergence audit helpers. All tests use PRIVATE scratch tables — the live kernel PML4 is only ever walked read-only, except template_mismatch_detected which clones it (freed afterwards).
