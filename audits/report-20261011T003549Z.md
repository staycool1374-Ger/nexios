## VERIFICATION (checks 1-6 of the audit request)

1. **Sufficiency for all arg-layout sizes — PASS.** `sp` is a strictly
   monotonically decreasing cursor from `stack_top - 8`; the highest byte the
   function can write is `sp - 8` (the `*--ptr` pre-decrement), and the 16-byte
   align step (`sp -= (16 - align)`) only moves down. Therefore
   `[stack_top-8, stack_top)` is never touched regardless of `argc`, `envc`,
   `str_total`, or alignment. Holds for both the runelf-empty-env path
   (`finalize_loaded_task` elf.cpp:619) and the `exec_into_current` non-empty
   argv/envp path (elf.cpp:788) — both use the same `setup_user_stack`, and the
   background `ElfLoader` (elf_loader.cpp:918) also routes through
   `finalize_loaded_task`. No off-by-one in the `str_total` copy
   (copy_strings writes exactly `sum(strlen+1)`).

2. **VULN-U2 reservation check — PASS.** `str_total + kStackReserve >= STACK_SIZE`
   is unchanged; `sp = stack_top - 8 - str_total - align` cannot underflow
   (both subtrahends are bounded by `STACK_SIZE` and the check keeps
   `str_total < STACK_SIZE - 2048`). The extra 8 bytes are far inside the
   2048-byte `kStackReserve` headroom (plus ≤15 alignment), so effective
   capacity is still safe.

3. **VA translation — PASS.** `user_rsp = ptr - stack_top + STACK_VADDR +
   PAGE_SIZE + STACK_SIZE` maps `stack_top` to the top of the mapped region, so
   `user_rsp` lands below the reserved canary slot and inside
   `[STACK_VADDR+PAGE_SIZE, STACK_VADDR+PAGE_SIZE+STACK_SIZE)`. Layout check
   with `argc=envc=0`: `envp[0]` sits at `user_rsp+16`, which `crt0.S:8`
   (`lea 16(%rsp,%rdi,8), %rdx`) reads as `&envp[0] = 0`. Matches the report.

4. **Reserve vs. relocate — PASS.** `canary_after[STACK] =
   STACK_VADDR+PAGE_SIZE+user_stack_size_-8` still brackets the region top;
   `canary_verify_user_segments` reads that exact VA and now finds it intact.
   `clone_err` copies `canary_before/after/installed` and re-arms
   (task.cpp:1764-1769); exec clears `canary_installed` before the swap and
   re-installs at exec tail (elf.cpp:821,904). No other consumer of
   `[stack_top-8, stack_top)` exists.

5. **Test honesty — PASS (discrimination), S3 (see findings).** Pre-fix the

   canary and exits 0 — the test discriminates. `CONFIG_ARCH_X86_64` is defined

6. **Probe build/packaging — PASS.** `userspace/envprobe.c` is picked up by
