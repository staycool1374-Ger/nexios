### [S1] — none

All safety-critical properties hold:

1. `vmm.cpp:1583-1598,1626-1637` (x86_64) — user-range 1 GiB (PDPT) and 2 MiB
   (PD) huge entries now `return false` instead of by-value copy. The
   detector (`entry & PAGE_HUGE`, PS bit 7, `vmm.hpp:419`) is the correct
   x86 huge indicator at both levels, and the old copy-as-is shared one
   writable page parent/child (silent aliasing — a cross-address-space
   integrity violation). Fail-closed is the only safe shape.
2. `vmm.cpp:1589-1593,1628-1632` (aarch64) — block detector
   `(entry & (PRESENT|TABLE)) == PRESENT` matches the documented descriptor
   encoding (`vmm.hpp:359-364`: table = bits[1:0]=11, block = 01). Encodings
   that could evade it (bits[1:0]=00/10) have bit 0 clear, so they are
   skipped by the preceding `PAGE_PRESENT` guard and can never reach the
   check. Complete.
3. `vmm.cpp:1705-1709,1726-1730` (riscv64) — leaf/block detector
   `(entry & (R|W|X)) != 0` matches Sv39 (`vmm.hpp:389-414`: table = V-only,
   leaf = V+R|W|X). The L0 check sits before any table
   alloc/install (no partial at that level); the L1 check fires after the
   zeroed `dst_l1` is installed — a USER-owned page reclaimed by teardown
   (see 5). No leak on any false path on any arch.
4. False-path partials are identically shaped to the pre-existing OOM
   partials: every installed table and data page on every branch comes from
   `PMM::alloc_user_page()` (USER-owned; `vmm.cpp:1563,1601,1640,1675,
   1712,1733,1755`), unvisited `dst` slots are zero (`memset` after alloc),
   and `free_user_pages` (`vmm.cpp:1389-1540`) frees exactly USER-owned
   tables/data via `is_user_page` on all three arch walks. Caller
   `task.cpp:1733-1737` destroys the child on false, and
   `cleanup` (`task.cpp:2131-2149`) documents this exact invariant
   ("a partially deep-copied address space (OOM during clone) is fully
   reclaimed here") and runs `free_user_pages` + `free_page(pml4)`.
   `stack_pdpt_phys_` is still 0 at the deep-copy call (`task.cpp:1739`
   assigns after), so the stack-PDPT teardown cannot misfire on a
   copy-failure child. No leak, no double-free, no alias.
5. Untouched leaf path re-verified (`vmm.cpp:1661-1682` x86/aarch64,
   `vmm.cpp:1748-1763` riscv): verbatim flags (`src & ~PAGE_FRAME_MASK`;
