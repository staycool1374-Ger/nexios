## INVARIANTS & CONCURRENCY BOUNDARIES
- **Presence split invariant:** `g_present` (software authority gate, used by cap/syscall/tests) and `g_live` (real hardware) are independent. `force_present(true)` sets `g_present` only — register access and IOTLB flush fire ONLY when `g_live`. Every existing `cap_iommu` test (software SL programming) keeps working unchanged with `g_live=false`.
- **Register access is serialized under the existing leaf `g_lock_`.** The IOMMU MMIO programming, RTADDR write, TE toggle, and IOTLB invalidation all hold `g_lock_`. `g_lock_` stays a LEAF lock: never held across `reschedule()`, never while calling cap/cspace/dispose/MemPool::free. Register reads/writes are short; bounded (≤ ~10 register ops + one invalidation descriptor).
- **Fail-closed enablement order:** RTADDR (root-table pointer) MUST be programmed and the passthrough context entries MUST be present BEFORE GCMD.TE=1. If RTADDR/passthrough pass fails, leave TE=0 (no translation) and set `g_live=false` (software-only). Never set TE=1 with an empty/unwired root table.
- **Kernel-DMA safety:** every kernel-owned device (AHCI, virtio) gets a T=0 passthrough Present context entry in the pre-pass so TE=1 does not block kernel DMA. Kernel DMA is NOT routed through a translation domain in this issue (documented).
- **IOTLB coherence:** every `map_frame`/`unmap_frame`/`domain_destroy`/`attach_device` that mutates an SL/context entry MUST, when `g_live`, issue a global IOTLB invalidation (and context-cache invalidation on attach/clear) before returning, so no stale translation leaks across domains. If the invalidation write is not acknowledged (GSTS/QIIWF timeout), fail the operation (return false) — never leave a stale mapping active silently.
- **No dynamic allocation on RT paths:** all DMAR parse data, passthrough entry list, and invalidation descriptors are static bounded arrays. Boot-time DMAR scan runs once pre-scheduler. `enable_translation()` and map/unmap use only existing static tables + `PMM::alloc_zeroed_table_page`.
- **Debug/release parity:** no `#ifdef CONFIG_DEBUG` changes control flow. `g_live`/`g_present` are plain bools, identical behavior in both builds (audit rule).
- **ResourceTracker:** passthrough context entries live in the existing static `g_ctx_tables`/`g_root_table` (fold into existing accounting, no new resource type). MMIO map of the IOMMU registers is a one-time boot mapping, not tracked per-test; live tests run under their own variant and must leave `occupied_domains()==0`.
- **`CONFIG_DEBUG_IPC_SCHED` must remain OFF** for all release-gate runs; no change touches it.

## STEP-BY-STEP CHANGES
1. **vtd.hpp**: add `namespace kernel::iommu::vtd::mmio` with offsets — `VER_REG=0x8`, `CAP_REG=0x10`, `GCMD=0x20` (TE=bit31, SRTP=bit30, QIE=bit26, IRTP=bit24, FL=bit31 for FECTL), `GSTS=0x24` (TES=bit31, RTPS=bit30, QIES, IRTPS), `RTADDR=0x28` (bits 51:12, bit0 RTT, bit10 TT), `FECTL=0xF0`, `FSTS=0xF4`, `FCTL=0xF8`, `IQH=0x80`, `IQT=0x90`, `IQA=0x88` (base+bit0 QEN). Add invalidation-descriptor layout: `INV_IOTLB` (type 0x1, granule bits, IV, T bits) and `INV_CTX` (type 0x2) constants.
2. **acpi.hpp/acpi.cpp (new, x86_64)**: implement `acpi::rsdp_locate()` — try multiboot2 tag 15 (RSDP v2) then 14 (RSDP v1) via `mb2_find_tag`; fallback scan of the legacy low-memory region (EBDA from `0x40E`, then `0x000E0000..0x000FFFFF`) for the "RSD PTR " signature (bounded scan). Validate checksum. From RSDP get XSDT (preferred, 64-bit) else RSDT; walk entries matching signature "DMAR"; parse `DmarTable { host addr 0xFED90000 default, flags, length }`, then walk DRHD structures: capture first remapping-unit `{segment, base_addr, flags, scope}`. Return a `dmar::DmarInfo` (pure data). All access via `HHDM_OFFSET + phys`; bounds-check every read against the table `length`; fail-closed (zeroed struct) on any malformed/checksum failure.
3. **iommu.cpp — split presence**: add `static bool g_live=false; static uint64_t g_mmio_base=0;`. `probe()` returns `g_present || g_live`. `force_present(p)` sets `g_present=p` (and `g_live=false`). Add `IoMmuManager::probe_hardware()`: call the ACPI DMAR parser; if a remapping unit is found, `VMM::map_page(HHDM_OFFSET + base, base, false)` (map the 4KiB MMIO page, framebuffer pattern), read `VER_REG` (must be non-zero and valid version) and `CAP_REG` (VT-d capability present); on success set `g_mmio_base=base`, `g_live=true`, `g_present=true`; else `g_live=false`, `g_present` unchanged (existing force state preserved). Return `g_live`.
4. **iommu.cpp — enable_translation()**: under `g_lock_` and `g_live`:
   a. Verify root table physical address via `kva_to_phys(&g_root_table[0])`.
   b. Program `RTADDR = (root_phys & 0xFFFFFFFFFF000)` (RTT=0, TT=0 — legacy root). Set SRTP in GCMD, spin-bounded (named constant) on GSTS.RTPS.
   c. **Passthrough pre-pass:** enumerate PCI config (CF8/CFC, `arch::pci_config_*`) for kernel devices — AHCI (class 0x0106) and virtio-net/blk (vendor 0x1AF4) — collect their BDFs into a static bounded array (`CONFIG_IOMMU_MAX_KERNEL_DEVICES`); for each, program a root entry (bus) + context entry with `Present | T=0` (passthrough) so kernel DMA is unaffected by TE=1. Skip any BDF already context-mapped by a user domain (attach_device). Fail (leave TE off) if the context-table pool (`CONFIG_IOMMU_MAX_BUSES`) exhausts.
   d. Set `GCMD.TE=1`; spin-bounded on `GSTS.TES`. If TES never sets, clear TE, set `g_live=false`, log, return false (fail-closed).
   e. Issue a global IOTLB + context-cache invalidation (step 5) before returning.
   Return true.
5. **iommu.cpp — iotlb_invalidate() (helper)**: under `g_lock_` when `g_live`: write one Queue-Invalidation Descriptor (`INV_IOTLB` with global granule + T) to the IQA ring; program `IQT`; set `GCMD.QIE`; spin-bounded on `GSTS.QIES`; on timeout return false. Also a `ctx_cache_invalidate()` (`INV_CTX` global) used by attach/clear. Call `iotlb_invalidate()` at the END of `map_frame`, `unmap_frame`, `domain_destroy` (after all entries cleared) and `ctx_cache_invalidate()` after `attach_device`/`clear_attachment`. If invalidation fails, the operation returns false (map/unmap already mutated tables — for unmap this is safe: the device can no longer reach the frame; document). Gate: these calls are no-ops when `!g_live`, preserving all existing software-table tests.
6. **iommu.cpp — fault handling (minimal)**: program `FECTL` to disable fault logging (`IP=1`, `TPH=1`); add `read_clear_faults()` that reads `FSTS` and writes back the read-clear bits (stub — no fault-log walk, no task kill; documented as a follow-up per spec §8.4). No IRQ enabled.
7. **kernel.cpp boot**: after `VMM::init()`/APIC init and after PCI/device probing is available, call `IoMmuManager::probe_hardware()` once (x86_64 only). Do NOT auto-call `enable_translation()` at boot (keeps default/`pc` boots and all non-IOMMU test runs on the software-only path; live enablement is invoked explicitly by the `iommu_live` test variant). Log presence/live state.
8. **Makefile — q35+iommu variant**: add a CLASS name `iommu_live`. In `_do_execute_test`, when `CLASS=iommu_live` (and `ARCH=x86_64`), append `-machine q35 -device intel-iommu,intremap=off,dma-translation=on` to `QEMU_FLAGS` for that invocation (and the FAT32/AHCI IDE drive stays; verify AHCI BDF under q35 is handled by the passthrough pass). Keep `execute-test ... all` and `selftest` on the default `pc` machine (no IOMMU) — the existing 12 `cap_iommu` software tests run there unchanged.

## SIL 3 / SAFETY RISKS
- **[S1] TE=1 with an unwired/empty root table hangs every DMA device (kernel AHCI/virtio blocked → device hang).** Mitigation: strict enablement order (RTADDR + passthrough T=0 entries FIRST, TE=1 LAST); fail-closed (TE stays 0) if RTADDR or the passthrough pass fails (step 4a–d); `enable_translation()` is explicit, not auto-at-boot.
- **[S1] Stale IOTLB translation leaks DMA access across domains after unmap/destroy (security boundary).** Mitigation: mandatory global IOTLB + context-cache invalidation after every SL/context mutation when `g_live` (step 5); invalidation-ack timeout fails the operation closed; unmap of a freed frame is always safe even if flush is delayed (frame freed only after).
- **[S1] Passthrough (T=0) entries accidentally covering a user driver device defeats isolation.** Mitigation: passthrough pass targets ONLY kernel class codes (AHCI 0x0106, virtio 0x1AF4) enumerated from PCI config; any BDF claimed by `attach_device` (user domain) is skipped/overridden; user device BDFs never get T=0.
- **[S1] Register programming with interrupts enabled mid-sequence / lock ordering vs `g_lock_`.** Mitigation: all register programming and invalidation under the single leaf `g_lock_`; bounded spin-waits (named constants); never release `g_lock_` inside a register op; never call into cap/cspace/dispose while holding it.
- **[S2] Unvalidated ACPI/DMAR table pointers → OOB read / wrong MMIO base.** Mitigation: every ACPI table access bounds-checked against declared `length`; RSDP/XSDT/RSDT/DMAR signature + checksum validated; malformed → zeroed `DmarInfo`, `g_live=false` (fail-closed).
- **[S2] `probe()` semantics change breaks existing 12 `cap_iommu` tests.** Mitigation: `g_present` (software) and `g_live` (hw) split; `force_present()` sets only `g_present`; existing tests never trigger register access; run `cap_iommu` to confirm 12/12.
- **[S2] DMAR MMIO base not identity-mapped in the boot PML4 → #PF on register access.** Mitigation: map the 4KiB MMIO page via `VMM::map_page(HHDM_OFFSET + base, base, false)` (framebuffer pattern) before any register read (step 3); fail-closed if mapping not possible.
- **[S2] QEMU machine change (`pc`→`q35`) alters PCI bus/BDF layout and IDE-drive wiring.** Mitigation: restrict q35 to the `iommu_live` CLASS only; passthrough pass enumerates PCI rather than hardcoding BDFs; verify AHCI still probes under q35 in the live variant.
- **[S3] Fault events silently lost (read-clear stub, no task kill).** Mitigation: document as follow-up (spec §8.4); FECTL disables fault log so no fault flood; read-clear keeps FSTS from stalling — no false "protection active" claim beyond the enabled scope.
