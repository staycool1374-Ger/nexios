## FINDINGS
- [S1] tools/meson/qemu_test.py (test() mapping + verdict parse) — Meson 30 s default timeout kills minute-long classes and parser is not specified fail-closed, risking systematic false FAIL and false PASS on zero-S-line/0-0 runs
  WHY: Long classes (core/selftest) exceed 30 s and empty-class stalls with zero S-lines are indistinguishable from hangs, so missing SUMMARY must map to FAIL/TIMEOUT, never PASS.
- [S2] tools/meson/postlink.py + test_lto_mode.py (three-builddirs + .lto-mode marker) — in-place LTO/buildtype toggle with assert-only mitigation re-creates the known LTO/NO_LTO object-mixing trap
  WHY: Mixed bytecode objects link silently wrong, so mismatch must wipe or split per-buildtype dirs, not just fail the build.
- [S2] tools/meson/gen_test_config.py + tools/meson/qemu_test.py (test-config embedding) — no dependency edge from -Dtest_class change to initrd/cpio/ISO re-stage and no pre-QEMU .baked-test-config gate plus missing release bake-none reset
  WHY: A stale staged initrd boots the wrong suite silently, the exact failure the stamp assert exists to prevent.
- [S2] tools/meson/package_iso.py + tools/meson/postlink.py (artifact staging) — riscv ELF-vs-BIN selection and debug-vs-release ISO separation are asserted but QEMU artifact choice per arch is not pinned in the runner contract
  WHY: Staging the ELF where QEMU expects the raw BIN (or the debug ISO over release) boots or debugs the wrong image.
- [S2] tools/meson/test_history.py + tools/meson/qemu_test.py (history + namespacing) — mkdir-lock lacks stale-lock timeout/trap cleanup and per-checkout namespacing by basename collides for same-dirname checkouts while :1234 stays non-namespaced
  WHY: A crashed holder wedges all future appends and colliding /tmp serial/verdict paths cause wrong PASS/FAIL attribution across checkouts.
- [S2] Makefile freeze + parity ledger (dual-system drift) — freeze is policy-only with no CI enforcement that a Makefile change requires a Meson mirror or ledger update
  WHY: Unenforced freezes drift by omission, so the ledger rots before the cutover gate runs.
