## Summary of change (as claimed, verified against diff + tree)

1. `install_user_yield_stub()` x86_64: kernel-placeholder search hoisted above `PMM::alloc_user_page()`/map, so the miss path (`original_entry == 0 → return false`) maps nothing. Old code allocated+mapped+copied then `free_page(stub_phys)` on miss while leaving the PTE installed (orphan U|X PTE to a freed page); new code eliminates that orphan. Verified: diff deletes the post-map `free_page` miss branch (old lines ~84-87) and returns before any allocation (new lines ~48-49).
2. riscv64 gate added: `if (frame == nullptr || !is_kernel_address(frame[31])) return false;` before any allocation; reaching `frame[31] = kUserYieldStubVa` implies stacked SEPC held a kernel-half placeholder. `frame` is `tcb.context.sp` built 8 lines earlier in `create_user()` (`stack -= 37; memset; stack[31] = entry`), OFF_SEPC=248 → idx 31 and SAVE_SIZE=296=37×8 confirmed in `src/kernel/arch/riscv64/syscall_entry.S:9,51,148`; `frame[31]` is in-bounds and the short-circuit null check precedes the dereference. Caller-supplied user entries now survive (x86-parity, by design).
3. aarch64: no code change — one added comment noting `context.elr_el1` rewrite is dispatched-dead (initial dispatch restores the stacked save area at `context.sp_el0`; `scheduler_switch.cpp:653-667,996-1009` validates/consumes the stacked ELR/SPSR, not the `elr_el1` field). Caller entry in the stacked frame therefore already survives; `exit_rip` reporting the stub is display-only. Verified code line `tcb.context.elr_el1 = kUserYieldStubVa` unchanged.
4. Docs: rationale block (`task.cpp:559-563`), `@brief/@post` on the installer, `create_user @param entry`, `task.hpp kUserYieldStubVa` — all accurately describe placeholder-only replacement. No `CONFIG_DEBUG` seam touched; per-arch `kUserYieldStub` bytes untouched (release stubs unaffected).
5. Expected coupled-protocol consequence (by design, not a defect): rv64 `debug_stop_fault_routed` control now fails deterministically at the poison assert (shared stub unmapped, entry survived) until the testbed half (poison `kSpinStubVa`) lands; kernel half alone is the forbidden push per the protocol.
